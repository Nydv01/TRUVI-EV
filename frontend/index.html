01 — About

What is TRUVI-EV?

Large Language Models hallucinate. We detect it.

TRUVI-EV is a multi-signal verification framework that determines whether claims generated by LLMs are factually supported, contradicted, or unverifiable based on retrieved evidence.

Unlike single-signal approaches, TRUVI-EV fuses four verification signals through a learned reliability gate — allowing the model to dynamically suppress unreliable evidence and amplify trustworthy signals.

Natural Language Inference using DeBERTa cross-encoder for entailment/contradiction detection
